This is a very basic twitter bot that favourites and reposts tweets based on specific keywords and even replies to some users whose tweets contain these keywords
We are using Tweepy library specifically designed to make twitter bots, a streamlit interface to monitor its actions.
The bot works, the API works, but unfortunately i have hit a paywall, i need to pay for the API in order to search for keywords on X, so the bot cant function without the paid API, however the bot can be rebuilt to post data using RSS feeds which are free of cost
